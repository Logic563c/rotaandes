# Créditos de las fotografías

Las fotografías se obtuvieron de Wikimedia Commons el 12 de noviembre de 2026. Antes de usarlas se verificó su licencia mediante la API de Commons (`extmetadata`): ambas son obra propia del autor y no tienen restricciones adicionales.

**Cambios realizados:** se redimensionaron a 1280 y 720 px de ancho y se convirtieron a WebP con calidad 70. No se alteró el contenido.
